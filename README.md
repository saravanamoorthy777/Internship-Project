# 🎓 Internship Management System

A web-based platform designed to streamline internship applications, tracking, and management for students, academic institutions, and employers.

---

## 🌟 Key Features

### 👨‍🎓 For Students
* **Live Job Board**: Search and filter internship opportunities by skills, stipend, and job type.
* **1-Click Application**: Apply directly with auto-populated profile and resume details.
* **Real-Time Status Tracking**: Monitor application lifecycle through interactive status badges (*Applied*, *Under Review*, *Interview Scheduled*, *Accepted*).
* **Profile & Resume Builder**: Manage personal info, university background, technical skills, and portfolio links.

### 🏢 For Employers & Recruiters
* **Job Posting Wizard**: Create customized internship openings with stipend specifications, required qualifications, and duration.
* **Applicant Screening & Kanban Pipeline**: Review candidate profiles, download resumes, and update application stages.
* **Candidate Evaluation**: Score applicants across technical and soft skill metrics with feedback notes.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, Tailwind CSS, JavaScript (ES6+), React.js
* **Backend**: Node.js, Express.js REST APIs
* **Database & Persistence**: MySQL / JSON Datastore with full CRUD operations
* **Version Control**: Git & GitHub

---

## 🚀 Getting Started

### 1. Direct Web Preview (No Setup Required)
Open `index.html` directly in any modern web browser or start a local HTTP server:
```bash
python -m http.server 3000
```
Then visit [`http://localhost:3000`](http://localhost:3000).

### 2. Backend REST API Server
```bash
cd server
npm install
npm start
```
The server will run on [`http://localhost:5000`](http://localhost:5000).
